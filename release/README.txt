RX7FC85 — FH2 Mod Platform car mod

Installation:
1. Close Forza Horizon 2 and Azimuth.
2. Extract this ZIP into the Azimuth folder (the folder containing azimuth.exe).
3. Keep BOTH d3dcompiler_47.dll and DWrite.dll from this package together there.
4. Start the game through Azimuth and check fh2-mods\platform.log.

Built with FH2 Mod Platform 2.8.0.
This mod registers MAZ_RX7_85 and applies car.sql.
The car ZIP, manifest, SQL patch and database audit are stored in RX7FC85\.

Important limits:
- The car ZIP must already contain models compatible with FH2. This builder does not convert FH6/FM5 model formats.
- This mod claims media\zipmanifest.xml. The platform allows only one mod to replace a given file.
  If another mod also replaces zipmanifest.xml, this mod will log an error instead of overriding it.
- Review RX7FC85\sql-audit.txt before installing. It lists every database table changed by the source package.
- Use only the database patch built from the clean FH2 base database supplied to the builder.
- Keep a backup of your save and game setup. Remove other mods newest-first when uninstalling layered changes.
