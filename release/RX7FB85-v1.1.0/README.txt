1985 Mazda RX-7 FB - Version 1.1.0

REQUIREMENTS
- Forza Horizon 2 for PC.
- Azimuth with FH2 Mod Platform 2.8.0 (API 9).

INSTALLATION
1. Close Azimuth and Forza Horizon 2.
2. Extract the contents of this archive into the Azimuth installation folder.
3. Merge the fh2-mods and RX7FB85 folders if Windows asks.
4. Start Azimuth and then Forza Horizon 2.

The car data and database patch are applied by FH2 Mod Platform.
Do not copy or replace the game's database manually.
