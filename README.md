## 1985 Mazda RX-7 FB — v1.1.0

Initial public release of the 1985 Mazda RX-7 FB mod for Forza Horizon 2.

### Requirements
- Azimuth
- FH2 Mod Platform 2.8.0 (API 9)

### Installation
Extract the contents of the downloaded ZIP into your Azimuth installation folder, preserving the folder structure.

The mod automatically registers the car and applies its database changes through FH2 Mod Platform.
