1985 Mazda RX-7 FB3S - Version 1.1.0

Created by Maxwell (Volticfist)

REQUIREMENTS
- Forza Horizon 2 PC v1.0.0.64
- Azimuth 0.9.10 or compatible
- Compatible FH2 Extra Options
- FH2 Mod Platform 2.8.0

INSTALLATION
1. Close Forza Horizon 2 and Azimuth.
2. Extract this archive into your Azimuth folder.
3. Merge the included folders with the existing folders.
4. Make sure RX7FB85.dll is inside fh2-mods.
5. Launch the game through Azimuth.
6. Check fh2-mods\platform.log.

CONTENTS
fh2-mods/RX7FB85.dll
RX7FB85/car.zip
RX7FB85/zipmanifest.xml
RX7FB85/car.sql

NOTES
Do not install alongside an existing manual import of this car.
Duplicate database entries can cause the SQL patch to fail.

The lighting and wiper assets are included.
The wiper animation may not be perfectly aligned.
A clean database installation still requires final testing.
